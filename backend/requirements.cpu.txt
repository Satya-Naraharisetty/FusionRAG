# CPU-only torch for Docker/Linux image builds.
#
# The extra index makes pip resolve `torch==2.13.0.*` to the 2.13.0+cpu wheel
# (no CUDA/nvidia dependencies) instead of the multi-GB CUDA build on PyPI.
# Every other dependency is identical to requirements.txt.
#
# Note: requirements.txt pins `torch==2.13.0.*` (prefix wildcard) because an
# exact `==2.13.0` pin cannot match the `2.13.0+cpu` local version.
--extra-index-url https://download.pytorch.org/whl/cpu
-r requirements.txt
